# Strange Mafia Game

**Strange Mafia Game** — многопользовательская пошаговая психологическо-детективная игра на базе Telegram и REST API, совмещающая живых игроков и AI-агентов (ботов под управлением локальных нейросетей через LM Studio).

Проект построен на **Kotlin**, **Spring Boot 3**, **Flyway**, **PostgreSQL**, **WebSocket** и **Telegram Bot API**.

## Особенности проекта
- **Гибридный состав**: недостающие слоты игроков заполняются AI-ботами на базе локальных LLM (через LM Studio).
- **Продвинутый промпт-инжиниринг**: нейросетевые игроки получают строгие, контекстно-адаптированные инструкции под свою роль и текущую фазу, а также напоминание о сдержанности в первый день.
- **Подробный валидатор ходов**: система возвращает понятные человеку и ботам описания ошибок (например: *"Нельзя выбирать самого себя в команду"*, *"Игрок 3 уже исключен"*).
- **Сквозная история событий**: все действия игры (`MessageEvent`, `DisconnectEvent`) нумеруются по порядку, сохраняются в PostgreSQL (`game_events`) и фильтруются по ролям игроков (мафия не видит ночных секретных сообщений агентов).
- **Приглашение друзей по ID**: при создании игры генерируется короткий ID, по которому друзья могут присоединиться в Telegram (`/join <ID>`).
- **Автоматические миграции**: схемы таблиц (`game_configs`, `game_states`, `users`, `game_events`) версионируются через Flyway.

## Правила и механика игры

В игре участвуют две противоборствующие стороны: **Мафия** (большинство) и тайные **Агенты** (меньшинство).

### Роли:
- **Глава Мафии (`MAFIA_HEAD`)** — публичный лидер мафии. Набирает команду на вылазку за артефактами. В конце дня решает: исключить подозреваемого игрока или проверить подлинность добытого ранее артефакта.
- **Мафия (`MAFIA`)** — обычный член мафии. Знает Главу Мафии, но не знает, кто тайные агенты. Помогает вычислять саботажников.
- ️**Глава Агентов (`AGENT_HEAD`)** — тайный лидер агентов. Знает всех своих агентов, а мафия считает его своим. Ночью может завербовать (шантажировать) рядового члена мафии или вернуть украденный мафией артефакт.
- **Агент (`AGENT`)** — тайный агент. Знает всех союзников-агентов. Днем маскируется под мафию. Если агент попадает в команду на вылазку, мафия вместо настоящего артефакта получает фальшивку (муляж).

### Фазы каждого дня:
1. **Дневное совещание (`DAY_CONVERSATION`)**: общее открытое обсуждение в чате.
2. **Выбор команды (`TEAM_CREATING`)**: Глава Мафии выбирает игроков в команду на вылазку (например, `2, 3`).
3. **Заключение дня (`DAY_CONCLUSION`)**: Глава Мафии вводит `Исключить <номер>` или `Проверить <номер>`.
4. **Ночное совещание (`NIGHT_CONVERSATION`)**: тайный чат агентов (сообщения не доставляются игрокам мафии).
5. **Заключение ночи (`NIGHT_CONCLUSION`)**: Глава Агентов вводит `Шантажировать <номер>` (вербовка) или `Вернуть <номер>` (возврат артефакта).

Игра завершается, когда истекают игровые дни.

## Архитектура модулей

Проект разделен на независимые модули Gradle:

```
strange_mafia_game/
├── domain/            # Чистая предметная область: GameState, Phase, Role, PromptHelpers, ansValidator
├── server/            # Spring Boot REST API + WebSocket, Flyway, PostgreSQL репозитории, игровой цикл
├── telegram_client/   # Spring Boot консольное приложение Telegram-бота (Long Polling)
└── lm_studio/         # HTTP-клиент к LM Studio / локальной LLM
```

## Запуск проекта

### 1. Подготовка базы данных
Убедитесь, что PostgreSQL запущен и создана база данных:
```sql
CREATE DATABASE mafia_game;
```
*(Все таблицы и индексы Flyway создаст автоматически при первом запуске сервера).*

### 2. Запуск LM Studio (опционально для ботов)
Запустите LM Studio, загрузите любую инструктивную модель (например, Llama 3 / Mistral / Qwen) и запустите локальный сервер.

### 3. Сборка проекта
В корне проекта выполните:
- **Windows (PowerShell)**:
  ```powershell
  .\gradlew.bat build -x test
  ```
- **Linux / macOS**:
  ```bash
  ./gradlew build -x test
  ```

### 4. Запуск сервера (`server`)
- **Windows (PowerShell)**:
  ```powershell
  .\gradlew.bat runServer
  ```
- **Linux / macOS**:
  ```bash
  ./gradlew runServer
  ```
Сервер запустится на `http://localhost:8080` и применит миграции Flyway.

### 5. Запуск Telegram-бота (`telegram_client`)
В отдельном терминале запустите клиент:
- **Windows (PowerShell)**:
  ```powershell
  .\gradlew.bat runClient
  ```
- **Linux / macOS**:
  ```bash
  ./gradlew runClient
  ```

## Как играть через Telegram

1. Откройте диалог со своим ботом в Telegram и отправьте `/start`.
2. **Создать новую игру**:
   - Отправьте команду `/create`.
   - Бот создаст лобби и пришлет персональный ID:
     ```
     Игра успешно создана!
     ID твоей игры: A8B1C2D3

     Отправь этот ID друзьям. Они смогут подключиться командой:
     /join A8B1C2D3

     Ожидаем подключения остальных игроков...
     ```
3. **Присоединиться к игре друзей**:
   - Друзья отправляют команду `/join A8B1C2D3`.
4. **Быстрый вход**:
   - Команда `/join` подключает к первой ожидающей игре в очереди.
5. **Игровой процесс**:
   - При старте бот сразу присылает каждому игроку его роль и список участников.
   - Если игрок ввел команду с ошибкой, бот пришлет подробную подсказку (например: *"Нужно выбрать ровно 2 игроков через запятую (выбрано: 1)"*).

## REST API и WebSocket

Сервер предоставляет полный программный интерфейс:

| Метод  | Путь                            | Описание                                                                          |
|--------|---------------------------------|-----------------------------------------------------------------------------------|
| `POST` | `/create`                       | Создать новую игру. Возвращает `gameId`.                                          |
| `POST` | `/join?gameId={id}`             | Присоединиться к конкретной игре или случайной.                                   |
| `GET`  | `/game/{id}/state`              | Получить актуальный `GameState` в формате JSON.                                   |
| `GET`  | `/game/{id}/events?from=X&to=Y` | Получить срез событий истории с ролевой фильтрацией приватных сообщений.          |
| `POST` | `/game/{id}/action`             | Совершить игровое действие (`{"userId": "...", "answer": "..."}`).                |
| `POST` | `/auth/register`                | Регистрация пользователя и получение токена авторизации.                          |
| `GET`  | `/auth/me`                      | Проверка профиля текущего токена.                                                 |
| `WS`   | `/game/{id}?token={token}`      | WebSocket поток уведомлений о событиях (`EventNotification(gameId, eventIndex)`). |

## Тестирование

Для запуска всех автоматических unit- и интеграционных тестов:

```powershell
.\gradlew.bat test
```

В проект включены:
- `GameStateValidationTest`: проверка валидатора ходов на всех фазах игры и проверка текстов ошибок `Exception`.
- `GameStateIterationTest`: проверка переходов состояний и стресс-тестирование 20 полных партий со случайными ходами.
- `GamesEventsTest`: тестирование диапазонных запросов событий и безопасности приватных сообщений.
- `AuthServiceTest`: тестирование токенов, ролей и прав доступа Root.
